# להיות אדם

מערכת לבניה וצמיחה אישית מ״עַיִר פרא״ לאדם גדול: דמות שנבנית במעשים, אלף מעשים בחודש, יומן ולוח שנה עברי.

זה המקום של **האפליקציה**: מכאן היא מותקנת במחשב, עובדת גם בלי אינטרנט, ומתעדכנת לבד.
הנתונים של כל אחד נשמרים רק במחשב שלו — שום דבר מהם לא נמצא כאן.
